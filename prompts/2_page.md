# Step 2. A visible website for your idea (15 minutes)

Get something on screen first, then make it real. Ask the AI:

> Read IDEA.md and AGENTS.md. Write web/index.html: a simple, good-looking page for my app with a title, one sentence on what it does, the input or drop-down the user will use, and a results table filled with 3 made-up example rows for now. Also write server/server.js: an Express server that serves the web/ folder on the PORT in .env. No database yet.

Run `npm start` and open <http://localhost:3000>.

**Checkpoint:** your idea is on screen. Change anything you don't like by asking the AI, and reload.
