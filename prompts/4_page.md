# Step 4. The page (15 minutes)

Ask the AI:

> Read IDEA.md and server/server.js. Write web/index.html: a page with a title, one sentence saying what the app does, an input or drop-down for [what the user picks], and a button that calls my /api/... route and shows the result as a table. Show a clear message if the request fails. Plain HTML, CSS, and JavaScript, no frameworks.

Restart the server (Ctrl+C, then `npm start`) and open <http://localhost:3000>.

**Checkpoint:** you can use your app in the browser and get real rows from the database.
